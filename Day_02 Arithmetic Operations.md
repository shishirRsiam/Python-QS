# ✅ **20 Math Problems (Only variables, assignment, print allowed)**

---

## **🔹 BASIC LEVEL (1–8)**

### **Q1.**

Create two variables `a = 5` and `b = 7`. These represent two numbers.
Print the sum of the two numbers.
**Expected Output:** `12`

---

### **Q2.**

Set `x = 9` and `y = 3`. These values represent two quantities.
Print the result of subtracting y from x.
**Expected Output:** `6`

---

### **Q3.**

Create two variables `num1 = 4` and `num2 = 6`.
Multiply them and print the total result.
**Expected Output:** `24`

---

### **Q4.**

Use variables `p = 20` and `q = 5`.
Print the result of dividing p by q.
**Expected Output:** `4.0`

---

### **Q5.**

Set `a = 10` and `b = 2`.
Print the result of `(a + b) + (a - b)` in one print statement.
**Expected Output:** `20`

---

### **Q6.**

Create variables `length = 7` and `width = 4` to represent dimensions of a rectangle.
Print the area using multiplication.
**Expected Output:** `28`

---

### **Q7.**

Create a variable `r = 3` representing the side of a square.
Print the perimeter using formula `4 * r`.
**Expected Output:** `12`

---

### **Q8.**

Set `num = 15` which represents a starting value.
Add 10 to it and print the final value.
**Expected Output:** `25`

---
